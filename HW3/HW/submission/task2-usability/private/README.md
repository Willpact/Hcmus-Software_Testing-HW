# Private participant evidence

Create these files locally after recruitment:

- `participant-register.md`
- `consent/P00-consent.md` through `consent/P07-consent.md`
- `recordings/P00.*` through `recordings/P07.*`
- any private contact-verification evidence requested by the course

This directory is ignored by Git to avoid publishing personal data. It must be
included manually in the final Moodle ZIP.

The participant register should contain:

| Study code | Real name | Target-profile fit | Masked Zalo/email/phone | Outside HW03 confirmed |
|---|---|---|---|---|
| P01 | | | | |

Mask the middle four phone digits, for example `091****789`. Do not upload this
information to an AI tool.
